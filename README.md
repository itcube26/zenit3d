# 🖨️ Конфигурация OrcaSlicer для 3D-принтеров ZENIT

Этот репозиторий содержит готовые профили принтеров, филаментов и процессов для слайсера **OrcaSlicer**, оптимизированные для линейки 3D-принтеров ZENIT (Series 300, DUO, HT и др.).

## 🚀 Быстрая установка (Рекомендуется)

Самый простой способ установить профили — использовать скрипт автоматической установки. Он автоматически определит вашу версию OrcaSlicer (Flatpak, Snap, AppImage или Deb) и установит файлы в правильную директорию.

Выполните следующую команду в терминале:

```bash
curl -sSL https://raw.githubusercontent.com/itcube26/zenit3d/main/install.sh | bash
```

После установки **перезапустите OrcaSlicer**. Профили ZENIT появятся в списке принтеров и филаментов.

---

## 📂 Ручная установка

Если вы предпочитаете устанавливать файлы вручную, скопируйте папки `printers`, `system` и `user` из этого репозитория в директорию конфигурации OrcaSlicer. 

Путь зависит от способа установки OrcaSlicer в вашей системе:

| Тип пакета | Путь к директории конфигурации |
| :--- | :--- |
| **Flatpak** (Рекомендуется) | `~/.var/app/io.github.softfever.OrcaSlicer/config/OrcaSlicer/` |
| **Snap** | `~/snap/orcaslicer/current/.config/OrcaSlicer/` |
| **AppImage** (x64 / ARM64) | `~/.config/OrcaSlicer/` |
| **Deb / RPM** (Нативный пакет) | `~/.config/OrcaSlicer/` |

### Пример ручной установки (для Flatpak):
```bash
git clone https://github.com/itcube26/zenit3d.git
cp -r zenit3d/printers zenit3d/system zenit3d/user ~/.var/app/io.github.softfever.OrcaSlicer/config/OrcaSlicer/
```

## 🛠️ Что включено в конфигурацию

- **Принтеры (`printers/`)**: Базовые конфигурации и макросы (AMS load/unload) для всех моделей серии ZENIT 300.
- **Системные профили (`system/`)**: 
  - Машинные профили (с разными диаметрами сопел: 0.4, 0.7 и др.).
  - Процессы печати (0.08mm Extra Fine, 0.15mm Optimal, 0.20mm Standard).
  - Библиотека филаментов (Generic и фирменные ZENIT PLA, PETG, ABS).
- **Пользовательские настройки (`user/`)**: Базовые пользовательские пресеты для быстрого старта.

---

## 🔄 Обновление конфигурации

Для обновления профилей до последней версии просто запустите скрипт установки повторно. Скрипт автоматически создаст резервную копию ваших текущих настроек с меткой времени перед заменой файлов.
